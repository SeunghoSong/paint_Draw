# 🖐️ Motion_Engine (동작 인식 & 제어 엔진 - Container C)

`Motion_Engine`은 **2번 비전 엔진(`Video_Engine`)**으로부터 전달받은 21개의 손 관절(Landmark) 좌표를 수학적으로 분석하여, 사용자의 의도(그리기, 지우기, 화면 이동, 확대/축소 등)를 실시간으로 판별하고 손떨림을 보정하여 **1번 웹 프론트엔드(`Web_Server`)**가 즉시 사용할 수 있는 정밀 제어 명령을 생성하는 마이크로서비스입니다.

---

## 🌟 핵심 구현 알고리즘 및 기술

1. **지수 이동 평균 손떨림 보정 (Exponential Moving Average, EMA):**
   * 카메라 좌표의 미세 떨림(Jitter)을 제거하여 만년필로 쓰듯 매끄러운 곡선 좌표 산출
   * 수식: $X_{\text{smooth}} = \alpha \cdot X_{\text{raw}} + (1 - \alpha) \cdot X_{\text{prev}}$ ($\alpha = 0.45$)
2. **다수결 투표 모드 디바운스 (Debounce State Machine):**
   * 최근 3프레임의 판별 결과를 큐에 보관하고 2프레임 이상 일치 시에만 모드를 변경하여 찰나의 손동작 튐(Glitch) 원천 차단
3. **선 끊김 방지 유예 버퍼 (Stroke Continuity Grace Period):**
   * 글씨를 쓰는 도중 일시적인 카메라 노이즈로 1~2프레임 인식이 흔들려도 선이 점선처럼 끊어지지 않도록 안전 버퍼 제공
4. **세션 기반 메모리 가비지 컬렉션:**
   * 10분 이상 지난 유휴 세션 메모리를 자동 청소하여 장시간 구동 시 메모리 누수 방지

## 📋 6대 제어 제스처 규격표

| 동작명 | `action` 값 | 제스처 조건 | 출력 좌표 및 데이터 |
| :--- | :--- | :--- | :--- |
| **그리기 (펜 모드)** | `"DRAW"` | **검지만 폄** (엄지/중지/약지/새끼 접힘) | `x, y`: 검지 끝(8번) 보정 좌표 |
| **지우개 모드** | `"ERASE"` | **검지 + 중지 2개 폄** | `x, y`: 두 손가락 중심 좌표 |
| **화면 이동 (드래그)** | `"PAN"` | **5손가락 모두 쥔 주먹 (✊)** | `pan_dx, pan_dy`: 이동 변화량 |
| **화면 천천히 확대** | `"ZOOM_IN"` | **주먹 쥐고 엄지만 폄 (👍)** | `delta`: `+0.008` (저감도 가속) |
| **화면 천천히 축소** | `"ZOOM_OUT"` | **주먹 쥐고 새끼손가락만 폄 (🤙)** | `delta`: `-0.008` (저감도 감속) |
| **대기 모드** | `"HOVER"` | **손바닥 전체 펴기** 또는 기타 상태 | `x, y`: 검지 끝 좌표 (미입력) |

## 🔌 API 인터페이스 명세

### 1. 헬스체크 (`GET /health`)
```json
{
  "status": "ok",
  "service": "motion_engine"
}
```

### 2. 제스처 분석 및 좌표 보정 (`POST /gesture`)
* **Request Body (JSON):**
  ```json
  {
    "session_id": "user_room_123",
    "landmarks": [
      {"x": 0.521, "y": 0.812, "z": -0.010},
      ...
      {"x": 0.560, "y": 0.280, "z": -0.040}
    ]
  }
  ```

* **Response (JSON):**
  ```json
  {
    "action": "DRAW",
    "x": 0.5582,
    "y": 0.2814,
    "delta": 0.0,
    "pan_dx": 0.0,
    "pan_dy": 0.0
  }
  ```
